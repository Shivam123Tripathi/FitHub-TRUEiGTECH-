FitHub is a full stack web application where users can explore fitness plans
and trainers, while trainers can manage plans through a dedicated dashboard.

This project was built to understand how a React frontend communicates with
a Spring Boot backend using REST APIs and JWT based authentication.

## Tech Stack
- Frontend: React, JavaScript, HTML, CSS
- Backend: Spring Boot, Java, Spring Security
- Database: MySQL
- Authentication: JWT
- Tools: Maven, GitHub

## Key Features
- User and Trainer registration & login
- Role based access (User / Trainer)
- Trainers can create and manage fitness plans
- Users can view and subscribe to plans
- Secure APIs using JWT authentication

## What I Learned
- How JWT authentication works in a frontend backend separated architecture
- Handling CORS issues between React and Spring Boot
- Structuring a Spring Boot project using controller, service and repository layers

## Problems Faced
- CORS errors while connecting frontend and backend
- Token handling and authorization issues
- React routing issues on page refresh
